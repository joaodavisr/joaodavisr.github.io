常见问题解答

罗技Hub是收费软件吗？ +
罗技Hub是免费软件，供所有罗技无线设备用户下载使用。下载和基础功能管理完全免费。
如何在两台电脑之间切换设备？ +
在罗技Hub中，您可以将设备添加到“多设备”列表。点击设备图标即可在已配对的设备间快速切换信号接收。
我的设备在罗技Hub中找不到？ +
请确保设备已开启蓝牙或接收器连接，并且电量充足。尝试在设备列表中点击“添加设备”进行搜索。如果仍无法识别，请检查是否需要更新驱动程序或固件。
罗技Hub支持哪些操作系统？ +
罗技Hub支持 Windows 10 (版本 1803 及以上) 和 macOS (版本 10.14 及以上)。对于 Linux 用户，请关注 Logitech Options 的 Linux 版本支持情况。
